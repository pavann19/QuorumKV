# Security policy

## Supported scope

Security fixes target current `main`; no separately supported stable-release series or response-time SLA is declared. This is a case study implementation, not evidence of production certification. Read the [transport and recovery boundary](docs/TRANSPORT_AND_RECOVERY.md) and [Raft ownership boundary](docs/RAFT_BOUNDARY.md).

## Reporting

Use [GitHub private vulnerability reporting](https://github.com/pavann19/QuorumKV/security/advisories/new). Include affected revision, minimal synthetic reproduction, expected boundary and observed impact. Do not include credentials, personal documents, real financial data or private infrastructure inventories.

Do not open a public issue with exploit details. Coordinate disclosure with the maintainer. Acknowledgement, severity and remediation are assessed from the report; no guaranteed response window is promised.
